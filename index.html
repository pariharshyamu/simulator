Local RAG Bench needs a local server

A real ONNX embedding model on WebGPU, over 1,302 chunks of plant material

Retrieval-augmented generation with a genuine embedding model and an optional local language model, measured rather than asserted: 31 hand-marked questions, recall@5 of 84% dense, 84% keyword, 90% hybrid, median query 43–48 ms. It is the one thing here that will not run from this page — it loads several hundred megabytes of model weights from disk, so it ships with a launcher instead.

Read how to run it →

Clone the repository, then cd rag-bench && python3 get-models.py small && python3 serve.py. Add --lan and phones on the same Wi-Fi can use the retrieval side; generation needs a secure origin, which a bare LAN address is not.

The finding that runs through all of it

Net heat rate already contains auxiliary power. Decompose it and Nashik's boiler and turbine are beating the norm — 2,440 against 2,458 kcal/kWh gross — while the entire 50 kcal/kWh penalty comes from auxiliary consumption at 12.96% against a norm of 10.75%. Koradi 8-10 is the mirror image: a genuine 176 kcal/kWh thermodynamic gap.

The two effects overlap by construction, so the ₹56.35 crore heat-rate gap and the ₹32.91 crore auxiliary excess must never be added together. Getting this wrong is the most expensive arithmetic error available in a station review.

Figures from the MAHAGENCO June-2026 energy bill, the provisional Part-I FSA bill including the F10 ECR calculation, and the MERC merit-order dispatch stack for July 2026. The ID fan sensor data inside the Theatre and the simulator is synthetic — a teaching artefact needs a fault whose true onset date is known exactly — and is labelled as such wherever it appears.
