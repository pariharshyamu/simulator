The Local RAG Bench

Local RAG Bench NEEDS A LOCAL SERVER

Real ONNX embeddingsWebGPU1,302 chunks

Retrieval-augmented generation with a genuine embedding model and an optional local language model, measured rather than asserted: 31 hand-marked questions, recall@5 of 84% dense, 84% keyword, 90% hybrid, median query 43–48 ms. It loads several hundred megabytes of model weights from disk, so it ships with a launcher instead of running from this page.

Clone the repository, then cd rag-bench && python3 get-models.py small && python3 serve.py. Add --lan and phones on the same Wi-Fi can use the retrieval side.
